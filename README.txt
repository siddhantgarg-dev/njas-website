NJAS EMBED V3

This version keeps the supplied product renders intact. There is no geometry generation or replacement product artwork.

New:
- Floating assets receive randomized initial rotations and subtle independent floating motion.
- Individual floating assets can be dragged around the stage.
- The main supplied configuration can be dragged horizontally to rotate it.
- Build Your Own is more functional: module counts, grip choice, configuration preview and surface colour treatment.
- Colour treatment is limited to CSS colour filters; the underlying supplied PNG geometry is unchanged.
- Pick Your Parts has Grips / Heads / Spines / Endcaps tabs using the supplied assets.
- Selecting a supplied full configuration changes the hero.
- Liquid glass remains around UI rather than being used to fake product geometry.
- Responsive layout remains isolated under #njas.

Important:
The CodeSandbox URL supplied as a rough outline could not be directly inspected by the browser environment, so this build follows the interaction/layout logic already established from your portfolio and the outline you supplied, while using the actual PNG assets you provided.
